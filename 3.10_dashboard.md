## 3.10.3 การอ่านค่า Supabase URL และ API Key

Dashboard อ่านค่า Supabase จาก `st.secrets`, environment variable หรือไฟล์ `config.json`

```python
def load_local_config():
    if not os.path.exists(CONFIG_PATH):
        return {}
    try:
        with open(CONFIG_PATH, "r", encoding="utf-8") as f:
            data = json.load(f)
        return data if isinstance(data, dict) else {}
    except Exception:
        return {}
```

ฟังก์ชัน `load_local_config()` ใช้อ่านไฟล์ `config.json` ถ้าไม่มีไฟล์หรืออ่านไม่ได้จะคืนค่าเป็น dictionary ว่าง

```python
def get_secret_or_env(name, default=""):
    local_cfg = load_local_config()
    try:
        if name in st.secrets:
            value = st.secrets[name]
            if value not in (None, ""):
                return str(value)
    except Exception:
        pass

    env_value = os.getenv(name)
    if env_value not in (None, ""):
        return str(env_value)
    cfg_value = local_cfg.get(name)
    if cfg_value not in (None, ""):
        return str(cfg_value)
    return str(default)
```

ฟังก์ชันนี้ใช้หาค่าการตั้งค่าโดยเรียงลำดับจาก `st.secrets`, environment variable, `config.json` และค่า default

```python
SUPABASE_URL = get_secret_or_env("SUPABASE_URL", DEFAULT_SUPABASE_URL).rstrip("/")
SUPABASE_KEY = get_secret_or_env("SUPABASE_KEY", DEFAULT_SUPABASE_KEY).strip()
```

บรรทัดนี้เป็นจุดที่ Dashboard ได้ค่า `SUPABASE_URL` และ `SUPABASE_KEY` เพื่อนำไปเชื่อมต่อ Supabase

```python
@st.cache_resource
def get_requests_session():

    session.headers.update({"apikey": SUPABASE_KEY, "Authorization": f"Bearer {SUPABASE_KEY}"})
    return session
```

ฟังก์ชันนี้ใช้ `@st.cache_resource` เพื่อ cache session เอาไว้ ไม่ต้องสร้าง connection object ใหม่ทุกครั้งที่ Streamlit rerun หน้าเว็บ

## 3.10.6 การดึงข้อมูลจาก Supabase

ฟังก์ชันหลักสำหรับดึงข้อมูลจาก Supabase คือ `fetch()`

```python
@st.cache_data(show_spinner=False)
def fetch(table, limit=20, order="timestamp", cache_bucket=0):
    url = f"{SUPABASE_URL}/rest/v1/{table}?select=*&order={order}.desc"
    if limit is not None:
        url += f"&limit={limit}"
    try:
        response = get_requests_session().get(url, timeout=SUPABASE_TIMEOUT_SECONDS)
        if response.status_code == 200:
            rows = response.json()
            print(
                f"[DASH_FETCH] table={table} status=200 rows={len(rows) if isinstance(rows, list) else 'n/a'}",
                flush=True,
            )
            return pd.DataFrame(rows)
        print(f"[DASH_FETCH] table={table} status={response.status_code} body={response.text[:240]}", flush=True)
    except Exception:
        import traceback
        print(f"[DASH_FETCH] table={table} exception", flush=True)
        traceback.print_exc()
    return pd.DataFrame()
```

ฟังก์ชันนี้รับชื่อ table เช่น `system_status` หรือ `part_records` แล้วสร้าง URL ไปยัง Supabase REST API โดยใช้ `select=*` เพื่อดึงทุกคอลัมน์ จากนั้นแปลงข้อมูล JSON ที่ได้เป็น `pandas.DataFrame`

## 3.10.7 การเตรียมข้อมูลผลตรวจชิ้นงาน

หลังจากดึงข้อมูลจาก `part_records` แล้ว Dashboard มีการจัดรูปแบบข้อมูลด้วยฟังก์ชัน `preprocess_part_records()`

```python
def preprocess_part_records(df):
    if df.empty:
        return df.copy()

    processed = df.copy()
    if "record_timestamp" in processed.columns:
        processed["_dt"] = pd.to_datetime(processed["record_timestamp"], errors="coerce")
    else:
        processed["_dt"] = pd.NaT

    if "part_id" in processed.columns:
        processed["_part"] = processed["part_id"].astype(str).str.strip()
    else:
        processed["_part"] = ""

    if "result" in processed.columns:
        result_norm = processed["result"].astype(str).str.strip().str.upper()
        processed["_result_norm"] = result_norm.replace({"GOOD": "PASS", "NG": "FAIL", "BAD": "FAIL"})
    else:
        processed["_result_norm"] = ""

    processed = processed.sort_values("_dt", ascending=False, na_position="last")
    processed["_date_text"] = processed["_dt"].dt.strftime("%Y-%m-%d").fillna("")
    timestamp_text = processed["_dt"].dt.strftime("%Y-%m-%d %H:%M:%S").fillna("N/A")
    part_text = processed.get("part_id", pd.Series("—", index=processed.index)).fillna("—").astype(str)
    processed["_match_label"] = timestamp_text + " | PART #" + part_text

    return processed
```

ฟังก์ชันนี้แปลงเวลา `record_timestamp` เป็น datetime, เตรียม `part_id` สำหรับค้นหา, แปลงผล `GOOD` เป็น `PASS` และ `NG` เป็น `FAIL` จากนั้นเรียงข้อมูลล่าสุดไว้ด้านบน

## 3.10.8 การดึงข้อมูลจากตาราง `system_status` และ `part_records`

ในส่วนหลักของ Dashboard มีการตรวจว่าเวลาควร refresh ข้อมูลหรือยัง แล้วดึงข้อมูลจาก Supabase

```python
# Streamlit should render in single-pass mode; avoid blocking loops that cause UI lag.
if True:
    now = datetime.now()
    now_utc = datetime.now(timezone.utc)
    now_ts = now.timestamp()
    last_sys_refresh_ts = st.session_state.get("_dash_last_sys_refresh_ts", 0.0)
    last_parts_refresh_ts = st.session_state.get("_dash_last_parts_refresh_ts", 0.0)
    needs_sys_refresh = (now_ts - last_sys_refresh_ts) >= SYSTEM_REFRESH_SECONDS
    needs_parts_refresh = (now_ts - last_parts_refresh_ts) >= PART_RECORDS_REFRESH_SECONDS
```

โค้ดนี้ตรวจเวลาล่าสุดที่ดึงข้อมูล หากเกินช่วงเวลาที่กำหนดไว้จะดึงข้อมูลใหม่

```python
    if needs_sys_refresh or "_dash_df_sys" not in st.session_state:
        sys_cache_bucket = int(now_ts // SYSTEM_REFRESH_SECONDS)
        st.session_state["_dash_df_sys"] = fetch("system_status", limit=1, order="id", cache_bucket=sys_cache_bucket)
        st.session_state["_dash_last_sys_refresh_ts"] = now_ts

    if needs_parts_refresh or "_dash_df_parts" not in st.session_state:
        parts_cache_bucket = int(now_ts // PART_RECORDS_REFRESH_SECONDS)
        st.session_state["_dash_df_parts"] = fetch(
            "part_records",
            limit=PART_RECORDS_FETCH_LIMIT,
            order="record_timestamp",
            cache_bucket=parts_cache_bucket,
        )
        st.session_state["_dash_df_parts_search"] = preprocess_part_records(st.session_state["_dash_df_parts"])
        st.session_state["_dash_last_parts_refresh_ts"] = now_ts
```

Dashboard ดึงข้อมูลล่าสุดจาก `system_status` จำนวน 1 record เพื่อแสดงสถานะเครื่อง และดึงข้อมูลจาก `part_records` เพื่อแสดงผลการตรวจสอบชิ้นงานทั้งหมด

```python

    df_parts = st.session_state.get("_dash_df_parts", pd.DataFrame())
    df_parts_search_base = st.session_state.get("_dash_df_parts_search", df_parts.copy())

        f"[DASH_STATE] df_sys_rows={len(df_sys)} df_sys_cols={list(df_sys.columns)} "

```

ข้อมูลที่ดึงมาแล้วจะถูกเก็บไว้ใน `st.session_state` เพื่อลดการดึงข้อมูลซ้ำจาก Supabase

## 3.10.10 การสรุปจำนวนชิ้นงานและ Yield

Dashboard คำนวณจำนวนชิ้นงานทั้งหมด จำนวนผ่าน จำนวนไม่ผ่าน และ Yield จากข้อมูลใน `part_records`


## 3.10.14 สรุปขั้นตอนการทำงานของ Dashboard

ลำดับการทำงานของ Dashboard จากโค้ดจริงสามารถสรุปได้ดังนี้

```text
เปิด dashboard.py ด้วย Streamlit
→ อ่านค่า SUPABASE_URL และ SUPABASE_KEY
→ สร้าง requests.Session พร้อม header apikey และ Authorization
→ ดึงข้อมูลจาก Supabase ตาราง system_status
→ ดึงข้อมูลจาก Supabase ตาราง part_records
→ แปลงข้อมูล part_records ด้วย preprocess_part_records()
→ อ่านสถานะล่าสุดของ Raspberry Pi, Robot, Printer, IP และ Modbus
→ คำนวณ Total, Pass, Fail และ Yield
→ แสดง Quality Summary, Inspection Detail, Recent Records และกราฟต่าง ๆ
→ refresh ข้อมูลตามเวลาที่กำหนด
```

ดังนั้น Dashboard ทำหน้าที่เป็นหน้าจอสำหรับติดตามข้อมูลจากระบบจริง โดยเชื่อมต่อ Supabase เพื่ออ่านข้อมูลผลตรวจชิ้นงานและข้อมูลสถานะเครื่อง แล้วนำมาแสดงเป็นตัวเลขสรุป ตาราง และกราฟ เพื่อให้ผู้ใช้งานสามารถติดตามภาพรวมของระบบตรวจสอบได้สะดวกขึ้น
