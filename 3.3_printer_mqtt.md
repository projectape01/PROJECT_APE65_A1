# 3.3 การเขียนโค้ดรับ MQTT จากฝั่งเครื่องพิมพ์ 3D

หัวข้อนี้อธิบายการรับข้อมูล MQTT จากเครื่องพิมพ์ 3D โดยอ้างอิงจากโค้ดจริงในระบบ ไฟล์หลักที่เกี่ยวข้องคือ `services/printer_service.py` และ `app.py`

ระบบใช้ MQTT เพื่อรับข้อมูลสถานะจากเครื่องพิมพ์ เช่น สถานะการพิมพ์ อุณหภูมิหัวฉีด อุณหภูมิฐานพิมพ์ เปอร์เซ็นต์งานพิมพ์ เวลาที่เหลือ และชื่องานพิมพ์ ข้อมูลที่รับมาจะถูกเก็บไว้ใน `_printer_status_cache` เพื่อให้ Web Application, Dashboard และระบบบันทึกข้อมูลนำไปใช้งานต่อ

## 3.3.1 การเรียกใช้ MQTT Library

ในไฟล์ `services/printer_service.py` มีการ import library ที่ใช้สำหรับเชื่อมต่อ MQTT ดังนี้

```python
import json
import os
import ssl
import time

import paho.mqtt.client as mqtt
```

ระบบใช้ `paho.mqtt.client` เป็น MQTT Client สำหรับเชื่อมต่อกับเครื่องพิมพ์ 3D และใช้ `json` สำหรับแปลงข้อมูล message ที่ได้รับจากเครื่องพิมพ์

## 3.3.2 การเริ่ม MQTT Thread จากโปรแกรมหลัก

ในไฟล์ `app.py` มีการ import ฟังก์ชัน MQTT จาก `services/printer_service.py`

```python
from services.printer_service import (
    apply_printer_finish_cleanup_unlocked as _apply_printer_finish_cleanup_unlocked_impl,
    get_printer_status as get_printer_status_impl,
    on_printer_connect as on_printer_connect_impl,
    on_printer_message as on_printer_message_impl,
    reset_printer_finish_cleanup_timer as _reset_printer_finish_cleanup_timer_impl,
    start_printer_mqtt_thread as start_printer_mqtt_thread_impl,
    update_printer_finish_cleanup_timer as _update_printer_finish_cleanup_timer_impl,
)
```

จากนั้นมีฟังก์ชัน wrapper สำหรับเรียกใช้งาน MQTT thread

```python
def start_printer_mqtt_thread():
    return start_printer_mqtt_thread_impl(sys.modules[__name__])
```

เมื่อโปรแกรมหลักเริ่มทำงาน จะสร้าง thread สำหรับ MQTT ดังนี้

```python
threading.Thread(target=start_printer_mqtt_thread, daemon=True).start()
```

หมายความว่า MQTT ของเครื่องพิมพ์จะทำงานเป็น background thread แยกจาก Flask Web Server ทำให้ระบบสามารถรับสถานะเครื่องพิมพ์ได้ตลอดเวลาโดยไม่รบกวนการทำงานหลักของ Web Application

## 3.3.3 การอ่านค่าการเชื่อมต่อเครื่องพิมพ์

ฟังก์ชันหลักที่ใช้เชื่อมต่อ MQTT คือ `start_printer_mqtt_thread(runtime)` ในไฟล์ `services/printer_service.py`

```python
def start_printer_mqtt_thread(runtime):
    while True:
        cfg = runtime.load_local_config()
        printer_ip = str(cfg.get("PRINTER_IP", "")).strip()
        access_code = str(cfg.get("ACCESS_CODE", "")).strip()
        serial_no = str(cfg.get("SERIAL_NO", "")).strip()
```

ระบบอ่านค่าจาก config ได้แก่

- `PRINTER_IP` คือ IP Address ของเครื่องพิมพ์
- `ACCESS_CODE` คือรหัสสำหรับเชื่อมต่อเครื่องพิมพ์
- `SERIAL_NO` คือ Serial Number ของเครื่องพิมพ์

ถ้าค่าเหล่านี้ไม่ครบ ระบบจะกำหนดสถานะเป็น `Config Missing`

```python
        if not (runtime.is_valid_ipv4(printer_ip) and access_code and serial_no):
            with runtime.data_lock:
                runtime._printer_status_cache["value"] = runtime._empty_printer_state(printer_ip or None)
                runtime._printer_status_cache["value"]["status"] = "Config Missing"
                runtime._printer_status_cache["value"]["task_name"] = "Set Printer Config"
                runtime._printer_status_cache["ts"] = time.time()
            time.sleep(2)
            continue
```

## 3.3.4 การสร้าง MQTT Client

หลังจากข้อมูล config ครบ ระบบจะสร้าง MQTT Client

```python
        client_id = f"test01-{os.getpid()}-{int(time.time()) % 100000}"
        client = mqtt.Client(
            callback_api_version=mqtt.CallbackAPIVersion.VERSION2,
            client_id=client_id,
            protocol=mqtt.MQTTv311,
        )
        client.user_data_set({"serial": serial_no})
        client.username_pw_set("bblp", access_code)
        client.on_connect = lambda c, u, f, r, p=None: on_printer_connect(runtime, c, u, f, r, p)
        client.on_message = lambda c, u, m: on_printer_message(runtime, c, u, m)
        client.tls_set(cert_reqs=ssl.CERT_NONE)
        client.tls_insecure_set(True)
```

โค้ดนี้กำหนด MQTT Client ID, protocol, username/password และ callback function ที่จะถูกเรียกเมื่อเชื่อมต่อสำเร็จหรือเมื่อได้รับ message จากเครื่องพิมพ์

ค่าที่ใช้เชื่อมต่อคือ

```python
client.username_pw_set("bblp", access_code)
```

โดย username คือ `bblp` และ password คือ `access_code` จาก config

## 3.3.5 การเชื่อมต่อไปยังเครื่องพิมพ์

ก่อนเชื่อมต่อ ระบบอัปเดตสถานะเป็น `Connecting`

```python
        with runtime.data_lock:
            runtime._printer_status_cache["value"]["ip"] = printer_ip
            runtime._printer_status_cache["value"]["status"] = "Connecting"
            runtime._printer_status_cache["value"]["task_name"] = "Connecting..."
            runtime._printer_status_cache["ts"] = time.time()
        runtime._printer_mqtt_client = client
```

จากนั้นเชื่อมต่อไปยังเครื่องพิมพ์ผ่าน port `8883`

```python
        try:
            client.connect(printer_ip, 8883, 60)
            client.loop_start()
```

เมื่อเชื่อมต่อแล้ว `client.loop_start()` จะเริ่ม loop ของ MQTT client เพื่อรอรับ message จากเครื่องพิมพ์

## 3.3.6 การ Subscribe Topic เมื่อเชื่อมต่อสำเร็จ

เมื่อ MQTT Client เชื่อมต่อสำเร็จ ฟังก์ชัน `on_printer_connect()` จะถูกเรียก

```python
def on_printer_connect(runtime, client, userdata, flags, rc, properties=None):
    reason_code = getattr(rc, "value", rc)
    serial_no = str((userdata or {}).get("serial", "")).strip()
    with runtime.data_lock:
        if reason_code == 0:
            runtime._printer_status_cache["value"]["status"] = "Connected"
            runtime._printer_status_cache["ts"] = time.time()
        else:
            runtime._printer_status_cache["value"]["status"] = f"Error {reason_code}"
            runtime._printer_status_cache["ts"] = time.time()
    if reason_code != 0 or not serial_no:
        return
    topic = f"device/{serial_no}/report"
    client.subscribe(topic)
```

ถ้าเชื่อมต่อสำเร็จ (`reason_code == 0`) ระบบจะกำหนดสถานะเป็น `Connected` และ subscribe topic:

```text
device/{serial_no}/report
```

topic นี้เป็นช่องทางที่เครื่องพิมพ์ส่งข้อมูลสถานะกลับมายังระบบ

หลังจาก subscribe แล้ว ระบบส่งคำสั่ง `pushall` ไปยัง topic request เพื่อขอข้อมูลสถานะทั้งหมดจากเครื่องพิมพ์

```python
    try:
        client.publish(
            f"device/{serial_no}/request",
            json.dumps({"pushing": {"sequence_id": "0", "command": "pushall"}}),
            qos=0,
        )
    except Exception:
        pass
```

## 3.3.7 การรับ MQTT Message จากเครื่องพิมพ์

เมื่อเครื่องพิมพ์ส่งข้อมูลมายัง topic ที่ subscribe ไว้ ฟังก์ชัน `on_printer_message()` จะทำงาน

```python
def on_printer_message(runtime, client, userdata, msg):
    try:
        packet = json.loads(msg.payload.decode("utf-8", errors="ignore"))
    except Exception:
        return
    info = packet.get("print")
    if not isinstance(info, dict):
        return
```

โค้ดนี้แปลง payload ที่ได้รับจาก MQTT เป็น JSON และอ่านข้อมูลใน key `print` หากข้อมูลไม่ถูกต้องจะ return ออกทันที

## 3.3.8 การอัปเดตสถานะเครื่องพิมพ์

หลังจากอ่านข้อมูลจาก MQTT แล้ว ระบบอัปเดตข้อมูลลง `_printer_status_cache`

```python
    with runtime.data_lock:
        state = runtime._printer_status_cache["value"]
        gcode_state = str(info.get("gcode_state") or state.get("status") or "Connected")
        if runtime._printer_finish_cleared and gcode_state.strip().upper() in {"FINISH", "COMPLETE", "COMPLETED"}:
            gcode_state = "IDLE"
        state["status"] = gcode_state if gcode_state else "Connected"
        if state["status"] == "Connecting":
            state["status"] = "Connected"
        update_printer_finish_cleanup_timer(runtime, state["status"])
        apply_printer_finish_cleanup_unlocked(runtime)
```

ส่วนนี้อ่าน `gcode_state` จากข้อมูล MQTT และใช้เป็นสถานะหลักของเครื่องพิมพ์ เช่น `RUNNING`, `FINISH`, `IDLE` หรือสถานะอื่น ๆ ที่เครื่องพิมพ์ส่งมา

จากนั้นอัปเดตข้อมูลอุณหภูมิและความคืบหน้าของงานพิมพ์

```python
        if "nozzle_temper" in info:
            state["nozzle_temp"] = runtime._as_float(info.get("nozzle_temper"), state["nozzle_temp"])
        if "bed_temper" in info:
            state["bed_temp"] = runtime._as_float(info.get("bed_temper"), state["bed_temp"])
        if "mc_percent" in info:
            state["percent"] = max(0, min(100, runtime._as_float(info.get("mc_percent"), state["percent"])))
        if "mc_remaining_time" in info:
            state["remaining_time"] = max(0, runtime._as_int(info.get("mc_remaining_time"), state["remaining_time"]))
```

ข้อมูลที่อัปเดตประกอบด้วย

- `nozzle_temp` อุณหภูมิหัวฉีด
- `bed_temp` อุณหภูมิฐานพิมพ์
- `percent` เปอร์เซ็นต์ความคืบหน้าของงานพิมพ์
- `remaining_time` เวลาที่เหลือ

ระบบยังอัปเดตชื่อไฟล์หรืองานพิมพ์

```python
        task_name = (
            info.get("subtask_name")
            or info.get("gcode_file")
            or info.get("project_name")
            or state.get("task_name")
        )
        if task_name:
            state["task_name"] = str(task_name)

        state["sub_stage"] = runtime._normalize_stage(info, state["status"], state.get("sub_stage"))
        state["last_updated"] = time.time()
        runtime._printer_status_cache["ts"] = time.time()
```

ส่วนนี้ใช้บันทึกชื่องานพิมพ์ สถานะย่อย และเวลาล่าสุดที่ได้รับข้อมูลจากเครื่องพิมพ์

## 3.3.9 การส่งคำสั่ง pushall ระหว่างเชื่อมต่อ

หลังจากเชื่อมต่อแล้ว ระบบจะส่งคำสั่ง `pushall` ซ้ำทุก 5 วินาที เพื่อขอข้อมูลสถานะล่าสุดจากเครื่องพิมพ์

```python
            while True:
                if runtime._printer_reconnect_event.is_set():
                    runtime._printer_reconnect_event.clear()
                    break
                if client.is_connected():
                    connected_once = True
                elif not connected_once and time.time() < connect_deadline:
                    time.sleep(0.2)
                    continue
                else:
                    break
                now = time.time()
                if now - last_push_ts >= 5.0:
                    try:
                        client.publish(
                            f"device/{serial_no}/request",
                            json.dumps({"pushing": {"sequence_id": str(int(now)), "command": "pushall"}}),
                            qos=0,
                        )
                    except Exception:
                        pass
                    last_push_ts = now
                time.sleep(1)
```

โค้ดนี้ทำให้ระบบขอข้อมูลจากเครื่องพิมพ์เป็นระยะ ๆ เพื่อให้สถานะที่แสดงในระบบเป็นข้อมูลล่าสุด

## 3.3.10 การจัดการเมื่อเชื่อมต่อผิดพลาด

หาก MQTT thread เกิด error ระบบจะกำหนดสถานะเป็น `Conn Error` และตั้งชื่อ task เป็น `Printer Offline`

```python
        except Exception as e:
            with runtime.data_lock:
                runtime._printer_status_cache["value"]["status"] = "Conn Error"
                runtime._printer_status_cache["value"]["task_name"] = "Printer Offline"
                runtime._printer_status_cache["ts"] = time.time()
            print(f"[MQTT] Error in thread: {e}", flush=True)
            if runtime._printer_reconnect_event.is_set():
                runtime._printer_reconnect_event.clear()
            time.sleep(2)
```

เมื่อออกจากการเชื่อมต่อ ระบบจะหยุด loop และ disconnect client

```python
        finally:
            try:
                client.loop_stop()
                client.disconnect()
            except Exception:
                pass
            runtime._printer_mqtt_client = None
```

## 3.3.11 สรุปการทำงาน

ลำดับการทำงานของ MQTT จากเครื่องพิมพ์ 3D คือ

```text
อ่าน PRINTER_IP, ACCESS_CODE, SERIAL_NO จาก config
→ ตรวจสอบว่าข้อมูลครบหรือไม่
→ สร้าง MQTT Client ด้วย paho.mqtt.client
→ ตั้ง username เป็น bblp และ password เป็น access_code
→ เชื่อมต่อเครื่องพิมพ์ผ่าน port 8883
→ subscribe topic device/{serial_no}/report
→ publish คำสั่ง pushall ไปยัง device/{serial_no}/request
→ รับ message จากเครื่องพิมพ์
→ แปลง JSON และอ่าน key print
→ อัปเดตสถานะเครื่องพิมพ์ลง _printer_status_cache
→ ส่งคำสั่ง pushall ซ้ำทุก 5 วินาทีเพื่อขอสถานะล่าสุด
```

ดังนั้นโค้ด MQTT ส่วนนี้ทำหน้าที่เชื่อมต่อกับเครื่องพิมพ์ 3D เพื่อรับสถานะการทำงานแบบต่อเนื่อง และนำข้อมูลดังกล่าวไปใช้แสดงผลใน Web Application, Dashboard และระบบ Cloud Logging ต่อไป
